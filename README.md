# AVOR Assistant

Seu espaço de trabalho, do seu jeito.

Notch para Windows com controles de música e letras, notas autoadesivas, calendário, sistema, arquivos e utilitários.

## Download

[Baixar AVOR Assistant 0.16.6 para Windows x64](https://github.com/avorlab/avor-assistant-releases/releases/tag/v0.16.6)

Versão de teste para Windows 10 2004 (build 19041) ou mais recente e Windows 11 com suporte x64. O instalador ainda não tem assinatura pública de editor.

**Dock e notificações do AVOR estão temporariamente desativados nesta versão.** A barra de tarefas, o menu Iniciar e as notificações do Windows permanecem nativos.

## Instalar e atualizar

Veja [as instruções de instalação](INSTALLATION.md). Quem usa a 0.16.3 precisa baixar e executar este instalador manualmente uma vez. Depois, Configurações → Sobre → Verificar se há atualizações consulta o GitHub, baixa o pacote e verifica seu tamanho/SHA256 antes de oferecer a instalação. [Detalhes do atualizador](UPDATES.md).

As preferências, notas e eventos são locais a cada usuário/computador. O pacote não inclui dados pessoais do desenvolvedor. Não é necessário desativar o antivírus.

Esta versão corrige uma chamada de efeito exclusiva do Windows 11 que podia impedir as configurações no Windows 10 com erro 0x80070057. [Compatibilidade, testes e limitações](COMPATIBILITY.md). O teste no Windows 10 real que apresentou o erro ainda precisa ser confirmado.

As letras acompanham o player; destaque por palavra depende dos timestamps fornecidos pela fonte. O acesso gratuito à API não representa autorização comercial irrestrita sobre as letras.

## Sobre este repositório

Este repositório distribui instaladores e documentação. O código do AVOR é mantido em repositório privado. Os componentes de terceiros mantêm suas licenças, com avisos e referências fornecidos junto da release.

Para relatar um problema, informe a versão do AVOR, a build do Windows, a escala de tela e os passos para reproduzir. Envie capturas sem informações pessoais.
