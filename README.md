# AVOR Assistant

Seu espaço de trabalho, do seu jeito.

Notch, dock, notas autoadesivas, calendário, controles de música, notificações e utilitários para Windows.

## Download

[Baixar AVOR Assistant 0.16.3 para Windows x64](https://github.com/avorlab/avor-assistant-releases/releases/tag/v0.16.3)

Esta é a primeira versão pública de teste. Requer Windows 10 2004 ou mais recente / Windows 11 com suporte a aplicativos x64. O instalador ainda não tem assinatura pública de editor.

Veja [como instalar](INSTALLATION.md), inclusive a preparação opcional das notificações. Não é necessário desativar as proteções do Windows.

As preferências e os dados são locais a cada usuário e computador. O pacote não inclui dados pessoais do desenvolvedor. Letras de músicas e atualização automática estão temporariamente desativadas.

## Sobre este repositório

Este repositório distribui instaladores, instruções e avisos de terceiros. O desenvolvimento do AVOR é mantido em repositório privado. Os componentes de terceiros conservam suas próprias licenças; os avisos e endereços dos projetos estão no arquivo de licenças que acompanha cada versão.

Para relatar um problema, informe a versão do AVOR e do Windows, os passos para reproduzir e uma captura sem informações pessoais.
